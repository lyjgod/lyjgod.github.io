# 🍪 "饼"不可少勋章服务

一个可爱的饼干徽章页面，专为手机访问优化，具有3D翻转效果和奖励展示功能。

## ✨ 功能特点

- 🍪 **真实饼干外观**：不规则形状，巧克力豆装饰
- 📱 **手机友好**：响应式设计，完美适配移动设备
- 🔄 **3D翻转效果**：点击徽章查看奖励信息
- 🎉 **奖励系统**：展示愿望券奖励
- 🌐 **Python服务**：Flask Web服务，支持局域网访问

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动服务
```bash
python app.py
```

### 3. 访问页面
- **电脑访问**：http://localhost:5000
- **手机访问**：http://你的电脑IP:5000

## 📱 手机访问步骤

1. 确保手机和电脑在同一WiFi网络
2. 查看电脑IP地址：
   - Windows: `ipconfig`
   - Mac/Linux: `ifconfig` 或 `ip addr`
3. 在手机浏览器输入：`http://电脑IP:5000`

### 修改端口
在 `app.py` 中修改：

